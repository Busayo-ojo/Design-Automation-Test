# Sign In Page

The `SignIn` component is the first authentication entry point for the FMDQ Data Reporting Portal (DRP), matching Figma frame **1.1 Sign in** (node `10303:161102`).

It composes the official design system building blocks:
- **`AuthBackground`**: Primary/900 dotted gold GLSL shader backdrop with vignette focus
- **`Logo`**: Official FMDQ Group brand asset
- **`Input`**: Standard design system inputs with user & lock iconography, password reveal toggle, and integrated field errors
- **`Button`**: Full-width primary button with loading feedback, and text button for password recovery
- **Support & Legal**: Integrated support enquiry mailto and SEC regulatory copyright notice

## Usage Guidelines

- Wrap sign in logic with client or server authentication callbacks (`onSubmit`).
- Set `loading={true}` while awaiting authentication responses; this automatically disables all form controls and toggles the action button to its de-activated loading state.
- Return user-friendly error banners via `error` for bad credentials, or field-level validation errors via `userIdError` / `passwordError`.
