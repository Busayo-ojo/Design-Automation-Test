# Empty State

The `EmptyState` component displays helpful fallback content when data, search results, notifications, or user records are empty.
Features all 19 official vector illustrations from the FMDQ Design System with full support for:
- **Color Variant** (`color: true`): Rich, vibrant branded palette.
- **Monochrome Variant** (`color: false`): Subtle greyscale outline for minimal or compact UI contexts.
