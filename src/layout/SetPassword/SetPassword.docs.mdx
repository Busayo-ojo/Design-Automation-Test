# Set Password

The `SetPassword` layout handles new password creation, password confirmation, and link expiry recovery for the FMDQ Data Reporting Portal (DRP Flow 1, nodes `10303:161691`, `10306:193920`, `10306:12547`, `10306:194016`).

## Overview

Key features:
- **Real-Time 4-Point Rule Checklist**: Evaluates entered characters against standard enterprise security criteria:
  1. At least 8 characters
  2. Upper and lower case letters
  3. At least one number
  4. At least one special character
- **Password Visibility Toggles**: Built-in toggle buttons using `<Icon name="eye" />` and `<Icon name="eye-slash" />`.
- **Mismatch Validation**: Highlights the confirmation field in error state with inline error text when passwords differ.
- **Onboarding Step 1 Support**: Renders the `"Step 1 of 2"` `<Badge>` and welcome copy for newly invited users.
- **Expired Link Recovery**: Gracefully handles 72-hour link expiry with a 56px clock security badge and a link request workflow.
