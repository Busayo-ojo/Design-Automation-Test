# Account Locked

The `AccountLocked` layout handles enterprise security lockouts for the FMDQ Data Reporting Portal (DRP Flow 1, nodes `10303:161403` and `10308:210995`).

## Overview

Key features:
- **Security Lock Badge**: 56px circular container in Error/50 (`#FEE4E2`) with bold `lock` icon in Error/600 (`#CB1A14`).
- **Clear Security Messaging**: Explains why the lockout occurred (repeated sign-in attempts vs 5 failed OTP verification codes).
- **One-Click Support Contact**: Primary button directly connects the user to the Market Service Group via `mailto:support@fmdqgroup.com`.
- **Back Navigation**: Small text button returning the user safely to the sign-in screen.
