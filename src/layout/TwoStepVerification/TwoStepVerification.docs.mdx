# Two-Step Verification

The `TwoStepVerification` layout implements the multi-factor authentication screen for the FMDQ Data Reporting Portal (DRP), corresponding to Flow 1 (nodes `10303:161632`, `10306:193869`, `10308:210820`, `10308:210896`, `10306:12638`).

## Overview

The layout features:
- **Card container**: `480px` wide, centered on the animated dotted shader background (`<AuthBackground>`).
- **Brand Identity**: FMDQ Logo with centered 56px circular `shield-tick` security badge.
- **6-Digit OTP Code Input**: 6 individual `52×60px` boxes with auto-focus advance, backspace handling, arrow key navigation, and full-clipboard paste distribution.
- **Warning and Attempt Alerts**: Integrates `<Toast>` banner variant when repeated incorrect codes are entered (`2 tries left`, `Last try before your account locks`).
- **Error States**: Highlights input boxes in red with error messaging below.
- **Resend Action**: Countdown timer formatting (`M:SS`) switching to an active underline button when cooldown expires.
- **Onboarding Step 2 Support**: Supports optional `<Badge>` (`Step 2 of 2`) and custom completion actions.
