# Forgot Password

The `ForgotPassword` layout handles self-service password recovery for the FMDQ Data Reporting Portal (DRP), corresponding to Flow 1 (nodes `10303:161451` and `10303:161517`).

## Overview

The component unifies two consecutive authentication states into a single clean layout:
- **`request` Mode (1.5)**: Renders the User ID entry form with a 56px circular security lock icon, user input field, "Send reset link" primary button, and back navigation.
- **`sent` Mode (1.6)**: Renders the email sent confirmation card with a 56px circular mail-check icon, explanatory instructions, "Back to sign in" secondary action, and a "Resend link" button.
