## Welcome

Welcome to the **FMDQ Design System** — the single source of truth for UI components, design tokens, and interaction patterns used across FMDQ's internal and external-facing products. Thereby helping FMDQ's product teams build more efficiently, at scale, and on brand. It is maintained by iQx and evolves regularly to meet the changing needs of FMDQ.

GOALS:
The design system aims to help UI consistency and quality, streamline the design and development process and provide guidance for design and development efforts. 
Whether you are building a new feature, maintaining an existing interface, or creating design mockups, this design system gives you everything you need to stay consistent, efficient, and on-brand.

### What Is the FMDQ Design System?

The FMDQ Design System is a centralised library of:

- **Reusable UI components** — pre-built, tested, and accessible interface elements.
- **Design tokens** — standardised values for colour, spacing, typography, and more.
- **Usage guidelines** — clear rules on how and when to use each element.
- **Code references** — ready-to-use code snippets aligned with design specifications.
- **Brand Checklist** — pre-submission gateway for every iQx application 

### Why It Exists

Consistency is critical in financial products. Users interacting with FMDQ platforms expect precision, clarity, and trust. The design system ensures that:

- Every developer ships interfaces that feel like FMDQ — not like disconnected products.
- Designers and developers speak the same language.
- New team members onboard faster with documented patterns.
- Maintenance and updates are applied once and reflected everywhere.
