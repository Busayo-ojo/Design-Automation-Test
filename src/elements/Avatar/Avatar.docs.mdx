# Avatars

Avatars represent user identities, contacts, or entities throughout the FMDQ application ecosystem.
Supports 3 presentation types (`Image`, `Initials`, `Icon`), 6 standardized scale sizes (`xs` through `2xl`), presence indicators (`online`, `offline`, `verified`), and grouped avatar stacking.
