# Badge

Badges highlight short status information, numerical counts, tags, and workflow categories.
Supports filled, accent, and outlined styles across brand and semantic color ramps (`blue`, `orange`, `success`, `warning`, `error`, `neutral`), optional leading/trailing icons, and compact avatar pairings.
