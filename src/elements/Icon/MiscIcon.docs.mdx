The `MiscIcon` component encapsulates the icon container primitives used for actions, avatar placeholders, and table cell contextual controls.
Derived directly from Figma component set `Misc icon` (`3354:173707`).

## Sizes

Supports 5 sizes: `xs` (24px), `sm` (32px), `md` (40px), `lg` (48px), and `xl` (56px) across `Square` (8px radius, 6px on xs) and `Round` shapes.

## Colors

Supports 6 palette colors: `Primary`, `Gray`, `White`, `Error`, `Warning`, and `Success`.

## Has Background (Table Row Menu Integration)

The `hasBackground` property (boolean, default: `true`) turns container fill and borders off while retaining the exact bounding box and center alignment.
This is used specifically in data tables where row heights are tight, allowing contextual dropdowns or action triggers without redundant card borders.
