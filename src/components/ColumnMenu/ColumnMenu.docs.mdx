## Anatomy

1. **Sort Section**:
   - `DropdownMenuItem` instances for ascending and descending ordering with linear arrow indicators (`arrow-up`, `arrow-down`).
2. **Dividers**:
   - 1px neutral-200 separator rules between sections.
3. **Filter Section**:
   - 12px caption header `"Filter"`.
   - Contextual filter controls based on column data type (`text`, `range`, `date`, `options`).
4. **Actions Section**:
   - `"Clear"` action text button in error/destructive styling.
   - `"Apply"` action text button in brand primary blue styling.
