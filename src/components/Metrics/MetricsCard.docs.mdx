## Compliance Summary Card (CASS)

Figma Component: `Metrics Card / Compliance` (`11039:683266`)

Compliance summary card designed for CASS workflows. Status follows the WRD rule (green compliant above 90%, amber below 90%). Supports continuous single progress bar or dual passed/failed split progress bar with 2px gap, plus two-tier breakdown figures.
