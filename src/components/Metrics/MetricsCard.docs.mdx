## Compliance Summary Card (CASS)

Figma Component: `Metrics Card / Compliance` (`11039:683266`)

Compliance summary card designed for CASS workflows. Status follows the WRD rule (green compliant above 90%, amber below 90%). Supports continuous single progress bar or dual passed/failed split progress bar with 2px gap, plus two-tier breakdown figures.

## Status & Market Participation Tile (CASS)

Figma Component: `Metrics Card / Status` (`11145:1002308`)

Compact interactive status count tile with click-to-reveal list for market participation (e.g. DMB live quoting activity).
Supports 3 semantic status types (`success`, `warning`, `error`) and 2 interactive states (`default`, `selected`).
Spec: 68px height, 12px outer padding, 24px Rubik SemiBold value, 10px DM Sans Regular label, bold status icons (`check-circle`, `info-circle`, `multiply-circle`), linear directional chevron, and optional vertical divider.
