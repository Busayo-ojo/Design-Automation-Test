## Notes

- **Reuse.** CTAs are the existing `Button` element; the dropzone's linear bar is the existing `ProgressBar` (with its label, metadata and footer suppressed, since Figma shows a bare bar with the percentage above it). Every icon comes from `foundations/icons`.
- **Tokens added.** Five colours had no existing match: `--color-file-jpg` (`#C548F1`), `--color-file-mp3` (`#6D56F8`), and the three tinted dropzone surfaces `--color-dropzone-uploading-surface`, `--color-dropzone-success-surface`, `--color-dropzone-error-surface`.
- **Scaling.** Figma scales these elements inside their compositions — the 24px file-type badge renders at 48 in the upload row and 45 in the dropzone; the 32px status circle renders at 48 and 56. Both components take a `size` prop and scale their glyph proportionally.
- **`Try Again` colour differs by context.** Figma uses `primary-700` for the label in the upload row but `primary-400` in the dropzone. Both are reproduced.
- **Bar height.** Figma's dropzone bar is 6px; the shared `ProgressBar` ships 8px at `size="sm"`, so the height is overridden within the dropzone only.

## Best practices

From Figma's Best Practices frame: keep the process simple with clear instructions; set and communicate file-size limits up front; give clear, immediate error messages; use progress indicators for large files; let users preview files before uploading; and accept a variety of file types while communicating any limitations.
