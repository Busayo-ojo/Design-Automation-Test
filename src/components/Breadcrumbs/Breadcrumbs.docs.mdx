## When to Use

- Breadcrumbs inform visitors of their current location in relation to the entire site hierarchy.
- Breadcrumbs improve the findability of site pages. The structure of the site is more easily understood because it is laid out in a breadcrumb.
- You should use breadcrumbs when you have a large amount of content organized in hierarchical structure with defined categories (multiple sections that can be divided into more sub-sections).

## Best Practices

- **Keep it simple**: Breadcrumbs should be simple and easy to understand. Use clear and concise labels that describe the page or section the user is in.
- **Place it in a prominent location**: Breadcrumbs should be placed in a prominent location on the page, such as near the top or above the main content area.
- **Use a logical hierarchy**: Use a logical hierarchy for the breadcrumbs that reflects the structure of the website or application. This can help users understand where they are in the overall navigation.
- **Use proper formatting**: Breadcrumbs should be formatted in a clear and consistent way. Use a clear visual indicator, such as a separator, to distinguish between different levels of the hierarchy.
- **Make it interactive**: Breadcrumbs should be interactive, allowing users to click on a previous page or section to quickly navigate back.
- **Don't overuse it**: Breadcrumbs should not be used as a replacement for a primary navigation system. Use them as a supplementary tool to help users keep track of their location.
