# Table

Data tables organize complex collections of structured records for operational scanning, comparison, and action execution.
Mirrors Figma's modular structure on `✤ Tables`, featuring standalone Header Cells (`2804:80528`), Leading Cells (`5604:43632`), and Content Cells (`5604:44353`), composable into flexible operational tables.
